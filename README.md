# SCM_HW1_Kadi
This repository was created for the SWE 442 Software Configuration Management homework.

The purpose of this repository is to demonstrate basic version control and change management practices using GitHub, including repository setup, branching, committing changes, pull requests, and issue tracking.

## Best Practices in Software Configuration Management

Best practices in software configuration management include using clear version control, writing meaningful commit messages, creating branches for new features, reviewing changes before merging, and tracking issues to document requested changes and improvements.
